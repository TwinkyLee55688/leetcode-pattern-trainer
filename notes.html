Quiz 1-10 Interview Sentences

Quiz 1: Contains Duplicate

I would use a hash set to track the numbers I have already seen. If the current number already exists in the set, I can immediately return true.

straightforward approach / track numbers already seen / immediately return true

Quiz 2: Two Sum

If the array is already sorted, I can use two pointers. Since the original problem does not guarantee sorted order and asks for original indices, I should use a hash map to look up complements.

does not guarantee sorted / original indices / look up complements

Quiz 3: Move Zeroes

Since we need to preserve the relative order of non-zero elements, I can use two pointers. One pointer scans, and the slow pointer tracks the next position where a valid element should be placed.

preserve relative order / in-place / slow pointer tracks next valid position

Quiz 4: Valid Anagram

I would use frequency counting. Since anagrams must have exactly the same character counts, I can count each character in both strings and compare the counts.

frequency counting / character counts / exactly the same

Quiz 5: Group Anagrams

The key insight is that anagrams should map to the same canonical representation. I can use either a sorted string or a frequency-count signature as the key.

canonical representation / frequency-count signature / group by same key

Quiz 6: Valid Palindrome

I can preprocess the string by keeping only alphanumeric characters and converting them to lowercase. To optimize space, I can skip invalid characters on the fly.

alphanumeric / lowercase / skip invalid characters on the fly

Quiz 7: Subarray Sum Equals K

My first instinct is sliding window because the problem involves continuous subarrays. However, if the array can contain negative numbers, the window sum is not monotonic, so I should use prefix sum with a hash map.

not monotonic / previous prefix sums / ending at current index

Quiz 8: Product of Array Except Self

For each index, the answer is the product of all numbers before it times the product of all numbers after it. We can compute this with one left-to-right pass and one right-to-left pass.

two passes / prefix products / suffix products

Quiz 9: Longest Substring Without Repeating Characters

This is a sliding-window problem. I would maintain a window with no repeated characters. The right pointer expands, and the left pointer moves forward when a duplicate appears.

window invariant / encounter duplicate / update maxLen

Quiz 10: Merge Intervals

Since merging depends on interval order, I should first sort by start time. Then I scan from left to right while maintaining the last merged interval.

sort by start time / maintain last merged interval / overlaps with
