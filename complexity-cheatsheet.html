3. Searching / Selection

Time:  O(log n)
Space: O(1) iterative

Invariant:
discard half every step.

lower_bound / upper_bound

lower_bound:
first index >= target

upper_bound:
first index > target

Time: O(log n)

Quickselect

Average: O(n)
Worst:   O(n²)

Idea:
partition once,
continue only on
the target side.

Time:  O(n)

Use when data
is unsorted and
no index/hash exists.
4. Graph Algorithms
Algorithm Time Space Why Typical Use
BFS O(V + E) O(V) Visit each node/edge once. Shortest path in unweighted graph.
DFS O(V + E) O(V) Visit each node/edge once. Components, cycle detection, traversal.
Dijkstra + Heap O((V + E) log V) O(V + E) Each relaxation may touch heap. Shortest path with non-negative weights.
Topological Sort O(V + E) O(V) Process each node/edge once. DAG dependency ordering.
Union-Find ~O(E α(V)) O(V) Each union/find almost constant. Connectivity, redundant edge, MST support.
Floyd-Warshall O(V³) O(V²) Triple nested DP. All-pairs shortest path.
5. Common Interview Patterns
Pattern Typical Time Space Core Reason
Two Pointers O(n) O(1) Each pointer moves forward only.
Sliding Window O(n) O(1) or O(k) Each element enters/leaves window once.
Prefix Sum build O(n), query O(1) O(n) Precompute cumulative information.
Monotonic Stack O(n) O(n) Each index pushed/popped at most once.
Heap Top-K O(n log k) O(k) Keep only k candidates in heap.
Backtracking usually exponential O(depth) Explore decision tree.
Dynamic Programming states × transitions number of stored states Cache repeated subproblems.
KMP O(n + m) O(m) Prefix table avoids rechecking.
Floyd Cycle Detection O(n) O(1) Slow + fast pointers.
